# Orvionix Studio — Static Website

A responsive, static website built from the supplied **Orvionix Studio Internal Overview (September 2026)**.

## Included
- `index.html` — complete one-page website
- `styles.css` — responsive styling and emerald / bottle green / ivory / gold visual system
- `script.js` — mobile navigation, scroll reveal and header interaction
- `assets/orvionix-logo.png` — logo artwork extracted from the supplied overview PDF

## Run locally
Open `index.html` directly in a browser, or serve the folder with any simple static server.

No build step is required.

## Source fidelity
The copy and service structure are based on the supplied internal overview. Founder positioning is intentionally broad: Shivani is presented across engineering and design, while Ricardo is presented across sales and marketing, so the studio is not narrowly positioned around a single discipline or vertical.
